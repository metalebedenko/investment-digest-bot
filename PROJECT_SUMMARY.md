# Project summary

Investment Digest Bot is a Python prototype for web research, model-assisted structuring, PDF generation and explicit Telegram delivery. Portfolio preparation was completed on 15 November 2026.

The prepared source includes a genuinely offline synthetic demo, exact dependencies, licensed fonts and 48 passing offline regression tests. A separate reviewer repeated the tests and added independent security probes. The review result is PASS_WITH_LIMITS, scoped to the published source and demo artifacts. Details and limitations are in docs/VALIDATION.md and docs/SECURITY-REVIEW.md.

Live provider/model/Telegram integrations, Windows execution and production hosting are not covered by those checks. The prototype makes no investment-performance claim. Runtime state and credentials stay local.
